Stepwise v1.6

Write one step per line, like 2x+4=10 then 2x=6. Press Enter for the next step. Click a line to edit it; it typesets as you type. The Solve button beside your last line works out the remaining steps and explains each one. Solve offline does the same with built-in rules and no AI: linear and quadratic equations, cubics and quartics (with exact radical roots when they are not rational), derivatives, many integrals (including by parts with polynomials), limits and simplifying. Each line is checked against the one above it. Calculus works too: d/dx(x^3), int(2x,x)=x^2+C, int(x,x,0,2), lim(sin(x)/x,x,0).

Connect Claude

Solve ▸ and Next step use Claude. Add your own API key to turn them on. Solve offline never needs a key.

Your key is stored only in this browser and is sent only to api.anthropic.com. Anyone who can use this browser can read it, so do not save it on a shared computer. Create a separate key with a spending limit in the Claude Console and delete it if you stop using it. Lines you solve with Claude are sent to Anthropic.
